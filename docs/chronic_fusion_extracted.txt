Gated fusion
What exactly is the Gating Network?
This is the part I would focus on most.
You have three CNNs:
M1​=VGG19 M2​=DenseNet201 M3​=MobileNetV2
Each produces a probability vector:
Pi​(x)∈RC
where C is the number of wound classes.
For your AZH dataset, your paper describes six classes: diabetic, pressure, venous, surgical, healthy, and background.
VGG19:
[0.05, 0.10, 0.70, 0.05, 0.05, 0.05]
DenseNet:
[0.08, 0.15, 0.60, 0.05, 0.07, 0.05]
MobileNet:
[0.10, 0.12, 0.55, 0.08, 0.10, 0.05]
The gating network receives information from these models and outputs:
VGG19       → 0.50
DenseNet    → 0.35
MobileNet   → 0.15
What should the Gating Network take as input?
This is where you have several choices.
Option 1 — Use only prediction probabilities
The simplest architecture:
P1(x) ─┐
P2(x) ─┼──→ Concatenate → MLP → Softmax → weights
P3(x) ─┘
Option 2: Use CNN feature representations
There is another possibility.
Instead of feeding only the final probabilities to the gating network, extract features from each CNN:
